cd 命令（Linux/Ubuntu）：绝对路径 vs 相对路径
cd = change directory，切换目录的命令。

  1. 绝对路径
    bash
    ￼
    ￼
    cd
    /path/to/directory
    ￼
    ✅ 特点：开头带 /，代表从根目录 / 开始，完整、唯一的地址，不管你现在在哪个文件夹，都能直接跳到目标位置。
    举例：cd /home/ubuntu/Desktop
    意思：直接去根目录下 → home → ubuntu → Desktop，无论当前在哪都生效
  2. 相对路径
    bash
    ￼
    ￼
    cd
    relative/path/to/directory
    ￼
    ✅ 特点：前面没有 /，是相对于你当前所在文件夹去找目标，起点是当前目录。
    举例：你现在在 /home/ubuntu，执行 cd Desktop/test
    意思：在当前目录里，找 Desktop 文件夹，再进里面的 test
